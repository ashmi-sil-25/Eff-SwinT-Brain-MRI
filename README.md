# Eff-SwinT Brain MRI Classification

A deep learning project exploring brain MRI image classification using EfficientNet-B2 and Swin Transformer (Swin-T).

## Overview

This project implements a deep learning workflow for brain MRI image classification, combining convolutional neural networks and transformer-based architectures.

## Models
- EfficientNet-B2
- Swin Transformer (Swin-T)

## Techniques
- Transfer learning and fine-tuning
- Data augmentation
- Hyperparameter optimization using Optuna
- Focal loss
- Ensemble predictions
- Grad-CAM visualizations

## Implementation

The project is implemented in Python using a Google Colab notebook.

**Notebook:** [`Eff+SwinT_ashmi.ipynb`](./Eff%2BSwinT_ashmi.ipynb)

## Current Status

The notebook has been uploaded to GitHub. Reproducibility, trained model checkpoints, and live inference deployment are planned as future improvements.
